keysright
=========

Test your typing accuracy and speed with real-time feedback.

Originally inspired by [keysleft.com](https://www.hanselman.com/blog/do-they-deserve-the-gift-of-your-keystrokes) - but inverted to focus on typing accuracy rather than keystroke mortality.

## Features

- Real-time typing speed (WPM) calculation
- Character accuracy tracking
- Backspace/Delete usage monitoring
- Text editing pattern detection (Ctrl+Shift+Arrow)
- Overall accuracy scoring

## Usage

Simply open `index.html` in a web browser and start typing the sample text. Your accuracy metrics will be tracked in real-time.
